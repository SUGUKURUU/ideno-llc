# 人材紹介・貨物軽自動車運送 業務委託 HP（仮）

新規開業（2026年8月予定）するクライアント向けのサンプルホームページの下準備。

## 背景

- 人材紹介事業と、貨物軽自動車運送の業務委託（軽貨物ドライバー募集）の2軸で開業予定
- まずはサンプルHPとして提案 → 受注済み。これから本実装する

## デザイン方針

- Bizreach (https://www.bizreach.jp) のページ構成（ヘッダー／ヒーロー／サービス紹介／強み／利用の流れ／募集要項／会社概要／お問い合わせ）を**構成の参考**にしている
- 文章・画像・配色・ロゴなど実際のコンテンツはコピーしていない（著作権上、不可）。すべて仮のダミー内容
- ideno-llc本体（ゴールド×ダークの高級路線）とは別ブランドのため、配色は別途仮設定（青系・プロフェッショナル路線）

## ページ構成

全6ページ。`Header`/`Footer` は `app/layout.tsx` で共通化している。

| URL | 内容 |
|-----|------|
| `/` | トップページ（ヒーロー／事業内容カード／選ばれる理由／利用の流れ） |
| `/service/jinzai` | 人材紹介サービスの詳細（特徴／流れ／FAQ） |
| `/driver` | ドライバー募集（募集要項／応募の流れ／FAQ） |
| `/company` | 会社概要 |
| `/contact` | お問い合わせフォーム |
| `/privacy` | プライバシーポリシー |

※特定商取引法に基づく表記は、通信販売（オンラインでの物販・有料サービスの直接販売）に該当する場合に必要なページ。今回のビジネスモデル（人材紹介・業務委託のマッチング）では現時点で必須ではないと判断し、未作成。必要になった場合は追加する。

## ローカルで続きを作業する

このディレクトリは独立した Next.js プロジェクト（独自の `package.json`）。ルートの `ideno-llc` プロジェクトとは別に、ここだけで `npm install` する。

```bash
cd clients/jinzai-driver-hp
npm install
npm run dev   # http://localhost:3000
```

将来的に別リポジトリへ切り出す場合は、このディレクトリをそのままコピーして独立したリポジトリにできる。
